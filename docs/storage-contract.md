# Khat & Co. — Storage & URL Contract

This document defines the exact keys and data shapes used by Khat & Co. for client-side persistence and URL hash sharing.
Under the **Absolute Zero Data Loss Rule**, these key names and data shapes must remain backward-compatible and never be deleted or renamed.

---

## 1. LocalStorage Keys

### `khat-and-co:draft`
Stores the active letter draft autosaved in the editor.

- **Storage mechanism:** `window.localStorage`
- **Serialization:** `JSON.stringify(letter: LetterData)`
- **Default value fallback:** Generated by `createDefaultLetter()` in `src/utils/storage.ts`

**JSON Schema Shape:**
```json

  "recipient": "Dearest Friend",
  "date": "Monday, September 28, 2026",
  "greeting": "My Dearest,",
  "body": "I am writing this from across the miles...",
  "signoff": "Yours always,",
  "sender": "Me",
  "templateId": "airmail-classic",
  "fontId": "caveat",
  "inkColor": "#1F2340",
  "ruledLines": true,
  "stickers": [
    {

```

### `khat-and-co:theme`
Stores the user's manual UI desk theme preference.

- **Storage mechanism:** `window.localStorage`
- **Values:** `"dark"` | `"light"`
- **Default value fallback:** `"dark"` (for ultra-premium stationery desk aesthetic)

## 3. URL Hash Contract (`#l=...`)
Used for zero-backend letter sharing to recipients.

- **Format:** `#l=<compressed_payload>`
- **Compression:** `LZString.compressToEncodedURIComponent(JSON.stringify(minifiedLetter))` with base64/URI fallback decoding in `src/utils/codec.ts`.
- **Minified Payload Shape:**
```json
{
  "r": "Recipient Name (up to 120 chars)",
  "d": "Date string (up to 80 chars)",
  "g": "Greeting string (up to 120 chars)",
  "b": "Letter body text (up to 6000 chars)",
  "s": "Signoff string (up to 120 chars)",
  "n": "Sender name (up to 120 chars)",
  "t": "templateId (string, validated against PAPER_TEMPLATES)",
  "f": "fontId (string, validated against HANDWRITING_FONTS)",
  "i": "inkColor (hex string)",
  "rl": 1,
  "st": [
    {
      "id": "stk_123",
      "sId": "wax-seal-heart",
      "x": 14.5,
      "y": 84.0,
      "sc": 1.0,
      "r": 0,
      "z": 2
    }
  ]
}
```

Backward compatibility rule: `decodeLetterFromHash` supports both minified property keys (`r`, `d`, `g`, `b`, `s`, `n`, `t`, `f`, `i`, `rl`, `st`, `sId`, `sc`) and full property keys (`recipient`, `date`, `greeting`, `body`, `signoff`, `sender`, `templateId`, `fontId`, `inkColor`, `ruledLines`, `stickers`, `stickerId`, `scale`).
